# Hi there, I'm Jay 👋

### Backend Developer | Java · Kotlin · Spring Boot

I'm a software engineering student aspiring to become a backend developer.

I enjoy building backend systems with a focus on **clear domain models, maintainable architecture, and reliable behavior**.
